# 卖 Put 年化收益计算

独立模块：`option_quant.analytics.put_annualized_return`。无新增依赖，不连接富途、不下单。初始年化已接入 [Put GUI](put_gui.md)；剩余持有期年化仍通过模块或离线示例使用。Risk Analysis 和 Event Analysis 暂不开发。

## 口径

只适用于未调整的标准美股期权，每张固定 100 股。所有金额必须同币种；权利金按每股报价，手续费默认按富途香港固定式套餐自动估算；如手动覆盖，传整笔持仓总额，不能再乘张数。调整合约不适用。

设 K 为行权价、N 为张数、M = 100 × N、D 为实际剩余天数。

| 项目 | 初始年化 | 剩余持有期年化 |
|---|---|---|
| 条件收益 B | 开仓权利金 × M − 开仓手续费 | 当前买回权利金 × M + 当前平仓手续费 |
| 全额担保分母 C | K × M | K × M |
| 简单年化 | B / C × 365 / D | B / C × 365 / D |

剩余持有期衡量的是“现在平仓”与“继续持有并无价值到期”的增量差异。持有可以省下现在的平仓手续费，所以它是加号。原始权利金及已付开仓费在两条路径中抵消，不再进入剩余收益，也不使用已赚利润。按本项目约定，无价值到期不发生交易，也不收取交易手续费；接货及其费用不在本计算范围内。

分母始终是全额行权现金担保 K × 100 × N，不提供其它资本口径。结果用 `gross_collateral` 表示该金额，不再重复存储同值的 `capital` 字段。

返回值是小数比率，`0.30` 表示 30%，展示用 `.2%`。计算不预先四舍五入、不复利，不假设全年能重复同样交易。忽略税费、现金利息和未输入的滑点；可将合理的成交成本反映在报价与费用参数中。

日期输入按自然日差计算（含周末、闰日），使用 ACT/365 固定 365 年化。若传时刻，必须同时提供带时区的估值与实际合约到期时刻；按 UTC 时间差保留不足一天的部分。不要把历史快照的目标 DTE 当成当前剩余天数。相同日期、过期、无时区时刻及混合类型报错，不将 0 天强行改成 1 天。到期日内请使用准确时刻；临近到期的年化可能很大。

## 离线示例与运行

`scripts/analyze_put_return.py` 仅展示客观计算结果，不判断是否开仓、持有或平仓。

在项目根目录 PowerShell 执行（或使用已安装本项目的 Python 环境）：

```powershell
$env:PYTHONPATH = "$PWD/src"
python scripts/analyze_put_return.py
python -m unittest discover -s tests -p test_put_annualized_return.py -v
```

假设行权价 50、开仓权利金 2、一张、剩余 30 天：估算卖出费 2.5275，初始年化 (200 − 2.5275) / 5000 × 365 / 30 = **48.05%**。之后剩余 14 天、买回报价 0.30：估算买入费 2.5075，剩余年化 (30 + 2.5075) / 5000 × 365 / 14 = **16.95%**。报价均为虚构示例，不是 IREN 实时行情。

## 接货与报价限制

这些值是“无价值到期且未被指派”条件下的年化展示，不是保证收益、概率加权预期收益或风险调整收益。美式 Put 可能提前被指派，需要按行权价买入每张 100 股；股价下跌损失可能远超权利金。价内 Put 的买回成本含内在价值，不能把这部分视作会自然消失的时间价值；高持有年化尤其不能证明值得继续承担接货风险。模块不预测到期股价或接货概率。

开仓宜传可成交卖价，平仓宜传可成交买回价（通常参考 ask），而非过期 last 或未经核实的 mid。调用方负责合约类型、报价时间、合约乘数及同一估值时刻的校验。当前 GUI 已显示全额现金担保分母、剩余天数、估算费用口径和接货风险提示；使用一张标准合约及自然日口径，暂不提供持仓视图或日内精确到期时刻。

参考：[OIC — Cash-Secured Put](https://www.optionseducation.org/strategies/all-strategies/cash-secured-put)。

## 富途手续费自动估算

费率来源：富途官方收费表第 4 节（https://www.futuhk.com/hans/support/topic2_283），核对日期 2026-09-28，期权监管费 2026-09-01 生效。仅适用于富途香港固定式套餐、标准美股个股期权，美元计价。

- 佣金：每股权利金 >0.10 时 0.65/张，否则 0.15/张；整笔订单最低 1.99。
- 平台费：0.30/张；期权监管费：0.0122/张；清算费：0.025/张；交收费：0.18/张；综合审计跟踪费：0.0003/张。
- 仅卖出收取 SEC 规费：交易金额 × 0.0000206，最低 0.01；交易活动费：0.00329/张，最低 0.01。

`opening_fee=None`（默认）估算卖出开仓费；`closing_fee=None`（默认）估算买回平仓费。传入数字可用实际账单费用覆盖，传 0 可显式忽略费用。无价值到期无需平仓交易，不另计交易手续费。

`transaction_fee` 在初始阶段是从权利金收入中扣除的开仓总手续费，在剩余阶段是持有至无价值到期可避免的买回总手续费（加到剩余潜在收益中）；`fee_estimate` 给出各项明细，`fee_source` 标明快照日期或手动输入。计算保留费率原始精度，展示到美分，未声称复刻券商各项取整规则。

这是假设单笔订单、单次成交、单腿的估算，不含优惠、阶梯套餐、分批成交的额外最低费用、指数期权附加费或接货费用。买卖都按各自费用计算，不能简单把开仓手续费乘 2。费率不会自动联网刷新，未来使用需核对该快照是否仍有效，账单金额可能因取整和成交拆分而不同。

剩余计算没有原始开仓权利金参数。已收取的权利金和已支付的开仓费均不再计入，只计算剩余买回成本，以及继续持有可避免的买回手续费。
